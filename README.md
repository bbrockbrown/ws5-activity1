## Steps 
1. clone this repository
2. `cd` into `frontend` and `backend` and run `npm i` in both 
3. after setting up your render.com database, create a `.env` file in both directories and use the `.env.example` files as reference 
4. run the following in respective directories: 
 - /frontend: `npm run start` 
 - /backend: `npm run dev`
5. if you already have data in your database test the queries
